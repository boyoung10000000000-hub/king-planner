빠른 실행
고객 · 매물 자동매칭
접수매물과 고객 희망조건을 비교해서 연결 가능성이 높은 조합을 보여줍니다.
자동매칭 기준
거래유형 일치 + 고객 희망조건과 매물명/메모의 공통 키워드 + 상태를 바탕으로 우선순위를 계산합니다.
24시간 연속 시간축 스케줄
매매=노랑 · 전세=초록 · 월세=하늘 / 고객·업무·메모·후기까지 한눈에
계약완료 매매 전세 월세 기타 카드 색상 = 거래유형 / 업무종류가 계약이거나 계약완료 고객과 연결된 일정 = 선명한 핑크
※ 하루·일주일은 상세 시간축, 한달은 압축 시간축, 1년은 12개월 요약으로 보여줍니다. 핑크색은 실제 계약완료 고객과 연결된 일정입니다.
고객관리
한 번 입력하면 자동 연결됩니다. 후속관리의 다음 약속 날짜·시간을 저장하면 일정표에도 자동 등록되고, 수정·종료하면 일정도 함께 정리됩니다.
● 진행중/대기 ● 계약완료 ● 타부동산 계약 ● 기타 종료 ● 전체보기
접수매물
전화로 받은 매물을 한눈에 보고, 일정의 ‘매물접수’ 기록과 자동 연결합니다.
만기관리
전세·월세 계약완료에서 입력한 만기일을 자동 연결해 6개월 전부터 관리합니다.
기본 원칙
최초 관리 시작: 만기 6개월 전 → 내 대시보드 알림 + 고객 문자 버튼
통화 후: 통화내용 기록 → 다음 알림 날짜 + 알림대상(없음 / 나 / 나+고객) 직접 선택
※ 실제 고객 SMS 자동발송은 외부 문자서비스 연결 전까지 ‘고객 문자’ 버튼으로 전송합니다.
계약완료
매매 · 전세 · 월세 계약을 한눈에 보고, 전세·월세는 만기 6개월 관리와 자동 연결합니다.
가계부
그날의 입금 · 지출을 기록하고 일 · 주 · 월 · 년으로 합계를 확인합니다.
